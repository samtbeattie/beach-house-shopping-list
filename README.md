# Beach House Shopping List

A simple, mobile-friendly webapp for managing your beach house supply needs. Keep track of what to bring, what's been packed, and what still needs to be picked up.

## Features

- **Add items** with a name, category, and quantity
- **Check off items** as you pack or purchase them
- **Filter by category** to focus on one area at a time
- **Clear purchased items** with a single tap when you're done
- **Suggested items** for common beach house supplies — add them in one click
- **Persistent state** — your list is saved to `localStorage` so it survives page refreshes

## Categories

Kitchen, Bathroom, Bedroom, Beach & Outdoor, Cleaning, Pantry

## Tech Stack

- [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/) for dev server and builds
- [Tailwind CSS v4](https://tailwindcss.com/) for styling

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
